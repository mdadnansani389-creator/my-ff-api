১. সিস্টেম পরিচিতি (Overview)



এই API-টি একটি উচ্চ ক্ষমতাসম্পন্ন Serverless RESTful Free Fire Player Information API। এটি কোনো মধ্যস্থতাকারী (Third-party) ওয়েবসাইটের ওপর নির্ভর না করে সরাসরি Garena Free Fire Official Game Server এর সাথে প্রোটোকল বাফার (Protobuf) ও AES এনক্রিপশনের মাধ্যমে যোগাযোগ করে। ফলে যেকোনো ফ্রি ফায়ার প্লেয়ারের ইন-গেম নাম, লেভেল, লাইক, র্যাঙ্ক, অ্যাভাটার, ব্যানার, পোশাক, পেট এবং ব্যাটল স্ট্যাটস নিখুঁতভাবে রিয়েল-টাইমে পাওয়া যায়।





    নিরাপত্তা ও প্রাইভেসি: এই API-তে কোনো ধরনের ইন্টারনাল বট তথ্য (যেমন Bot UID) পাবলিক রেসপন্সে প্রকাশ করা হয় না। এটি ১০০% প্রোডাকশন-রেডি ও ক্লিন JSON আউটপুট প্রদান করে।

৪. ফিল্ড ডিকশনারি (Field Descriptions)


    
    
  • AccountInfo.AccountName: প্লেয়ারের বর্তমান ইন-গেম ডিসপ্লে নেম (স্টাইলিশ ফন্ট ও ইউনিকোড সাপোর্ট করে)।
    • 
    
  • AccountInfo.AccountLevel: প্লেয়ারের বর্তমান গেম লেভেল।
    • 
    
  • AccountInfo.AccountLikes: মোট সংগৃহীত প্রোফাইল লাইক সংখ্যা।
    • 
    
  • AccountInfo.AccountEXP: প্লেয়ারের সংগৃহীত মোট এক্সপেরিয়েন্স পয়েন্ট।
    • 
    
  • SocialInfo.signature: প্লেয়ারের ইন-গেম বায়ো বা সিগনেচার।
    • 
    
  • BattleStats: সলো, ডুও এবং স্কোয়াডে মোট খেলা ম্যাচ, জয়, কিল, ড্যামেজ ও হেডশটের সংখ্যা।
    •

৬. ইন্টিগ্রেশন কোড উদাহরণ (Integration Code)



JavaScript (Web / Node.js)


const uid = "YOUR_UID";
fetch(`https://my-ff-api-three.vercel.app/api/player-info?uid=${uid}`)
  .then(res => res.json())
  .then(json => {
    if (json.success) {
      console.log("Name:", json.data.AccountInfo.AccountName);
      console.log("Level:", json.data.AccountInfo.AccountLevel);
      console.log("Likes:", json.data.AccountInfo.AccountLikes);
    }
  });



Python


import requests

url = "https://my-ff-api-three.vercel.app/api/player-info?uid=YOUR_UID"
data = requests.get(url).json()

if data.get("success"):
    player = data["data"]["AccountInfo"]
    print(f"Player: {player['AccountName']} | Lv: {player['AccountLevel']}")



PHP


<?php
$uid = "YOUR_UID";
$url = "https://my-ff-api-three.vercel.app/api/player-info?uid=" . urlencode($uid);
$response = file_get_contents($url);
$result = json_decode($response, true);

if (!empty($result['success'])) {
    echo "Player: " . $result['data']['AccountInfo']['AccountName'];
}
?>
